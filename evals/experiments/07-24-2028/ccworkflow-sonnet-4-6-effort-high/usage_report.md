### What went wrong
- **8 agents interrupted** (plus 2 active at pause). Parallel author agents for Group 2 hit tool interrupts mid-flight and held stalled slots.
- **No integrate ran for Group 2**. abb36a (the $20.53 integrate G2 agent) was active when the workflow was paused — it exists in the main session transcript, not the workflow archive.
- **Build broken at pause**: human test run shows 132/272 (all Zjj, W-jj, W+jj quark processes fail), consistent with partially-authored W2jet files on disk but no integrate/fix pass.
- **Cache read dominates cost.** 94% of total tokens are cache reads (74M of 78.7M). The integrate G2 agent alone consumed ~28M cache read tokens, indicating extremely deep context re-reads per fix iteration.

### Recommendations for re-run
- Set a **fix round limit** (`fixRounds`) on the integrate agent to prevent runaway fix loops.
- Consider a **shorter context / fresh agent** strategy for integrate: if fixes exceed N rounds, spawn a fresh agent with only the relevant diff context rather than accumulating 400+ messages.
- The parallel author model is sound for confirmed-working units, but **interrupted author agents waste cost** without producing usable output. Investigate the interrupt source (likely a permission prompt or timeout).
